## Purpose
The EnhancedProbeDriver aims to extend the current ProbeDriver functionality with new features, parameters, and capabilities while maintaining the established architectural patterns and shared type system.

- Maintain compatibility with shared packages (percent_lut_pkg)
- Follow established state machine and status register patterns
- Ensure synthesis compatibility and performance
